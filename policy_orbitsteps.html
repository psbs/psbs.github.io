Orbit Steps privacy policy

Effective 8 October 2026 · App package com.orbitsteps.game

Orbit Steps is an offline puzzle game for Android in which the player programs a small robot. It can be played by children and adults. This policy explains what the game does with information. The short version: it doesn't collect, send or share any.

Information the game collects

None. Orbit Steps has no account, no sign-up, no advertising, no in-app purchases, no analytics, no crash reporting and no third-party tracking code. It doesn't ask for a name, age, email address or any other personal detail. The game requests no Android permissions, including the Internet permission, so it can't send anything from the device.

Information stored on the device

So that a player can continue where they stopped, the game keeps the following in its own private storage on the device:

  • which levels have been finished and how many stars were earned;
  • the unfinished program on each level;
  • the robots, colours and badges earned and the ones chosen;
  • settings: sound effects, music, reduced motion and slow playback.

None of this identifies a person, and the developer never receives it. It is deleted when the game is uninstalled or its data is cleared in Android's settings.

Children

The game is suitable for children and is built so that there is nothing to protect them from inside it: no advertising, no purchases, no chat, no user-made content, no links to shops or social networks, and no collection of information from anyone. A parent or guardian doesn't need to give consent for data collection, because there is none.

Links

The only link in the game is the one to this page, in Settings → About. It opens the device's web browser. The game itself doesn't go online.

Sharing

Orbit Steps doesn't share data with anyone, because it has none to share.

Changes

If this policy changes, the updated version will be published at this address with a new effective date. Any future version that changed what the game collects would say so here before release.
